# Sales-Dashboard-Analysis-Tableau-
jnkThis project is a comprehensive sales analytics dashboard built in Tableau to track and visualize key business metrics across multiple dimensions.

### Key Metrics Analyzed:

* Revenue – Total income generated from sales.
* GMV (Gross Merchandise Value) – Total value of merchandise sold.
* AOV (Average Order Value) – Average value per order.
* Number of Orders – Count of total orders.
* Total Discount – Sum of discounts offered.

### Dimensions & Insights:

* Customer Segmentation: Sales analyzed by income range and age groups.
* Product & Department Analysis: Department-wise and store-wise sales trends.
* Time Analysis: Week-wise sales trends to identify patterns and seasonality.

### Features:

* Interactive dashboards for easy filtering and exploration.
* Dynamic visualization of sales performance across multiple dimensions.
* Insights into customer buying behavior and store performance.

### Tools Used: 
Tableau Desktop / Tableau Public
